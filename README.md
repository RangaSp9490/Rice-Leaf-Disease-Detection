# PRCP-1001 Rice Leaf Disease Detection\n\nOpen `PRCP_1001_Rice_Leaf_Disease_Detection.ipynb` in Jupyter and run all cells. The notebook downloads the dataset from the URL supplied in the project brief. Install dependencies with `pip install -r requirements.txt`. It includes EDA, preprocessing, augmentation, CNN, MobileNetV2, EfficientNetB0, evaluation, model comparison, prediction and project reports.\n\nThe dataset is very small (120 images according to the brief); metrics are exploratory and do not prove production readiness.\n
